# Guía de Contribución

¡Gracias por tu interés en contribuir a WebClasesOnlineAmerica! 🎉

## 🚀 Cómo Contribuir

### 1. Fork el Proyecto

Haz fork del repositorio y clónalo localmente:

```bash
git clone https://github.com/TU_USUARIO/WebClasesOnlineAmerica.git
cd WebClasesOnlineAmerica
```

### 2. Crea una Rama

```bash
git checkout -b feature/mi-nueva-funcionalidad
```

### 3. Haz tus Cambios

- Escribe código limpio y bien documentado
- Sigue las convenciones del proyecto
- Agrega tests si es necesario
- Actualiza la documentación si es relevante

### 4. Commit tus Cambios

```bash
git add .
git commit -m "feat: agregar nueva funcionalidad"
```

Usa mensajes de commit descriptivos:
- `feat:` para nuevas funcionalidades
- `fix:` para correcciones de bugs
- `docs:` para documentación
- `style:` para formato
- `refactor:` para refactorización
- `test:` para tests

### 5. Push y Crea un Pull Request

```bash
git push origin feature/mi-nueva-funcionalidad
```

Luego crea un Pull Request en GitHub.

## 📋 Estándares de Código

- Usa TypeScript para el frontend
- Sigue las reglas de ESLint
- Mantén el código formateado
- Escribe comentarios cuando sea necesario

## 🐛 Reportar Bugs

Si encuentras un bug, crea un Issue con:
- Descripción clara del problema
- Pasos para reproducirlo
- Comportamiento esperado vs actual
- Screenshots si aplica

## 💡 Sugerir Funcionalidades

Abre un Issue con:
- Descripción detallada
- Casos de uso
- Beneficios

¡Gracias por contribuir! 🙏
