## 🎓 Platform Highlights

- **Automated Video Conferencing:** Hooks into Google Calendar and Google Meet APIs to generate verified room links upon booking.
- **Interactive Student & Teacher Portals:** Role-specific interfaces for setting availability, accepting bookings, and managing course materials.
- **State-of-the-Art Architecture:** TypeScript throughout frontend and backend services for strict type safety and zero runtime surprises.
- **Production-Ready Documentation:** Extensive deployment documentation (`DEPLOY.md`, `ROADMAP_PRODUCCION.md`, `COMO_PROBAR.md`).

## 🚀 Quickstart

```bash
# Clone the repository
git clone https://github.com/ExeDevCentral/TuProfeOnline.git
cd TuProfeOnline

# Install dependencies
npm install

# Run development server
npm run dev
```
